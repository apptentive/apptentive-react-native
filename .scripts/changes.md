- Apptentive Android SDK: 7.4.0
- Apptentive iOS SDK: 7.4.0

#### Breaking Changes

- The minimum supported iOS version is now 15.0 (required by ApptentiveKit 7.4.0)

#### New & Improved

- Added support for the Canada (`CA`) region on iOS (already supported on Android)
- The SDK can now be remotely disabled (kill switch)
- Interaction throttling is now configured from the server
